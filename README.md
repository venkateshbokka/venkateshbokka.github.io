## Featured Project

### Sensor to Blender
A digital twin concept that connects industrial telemetry to a 3D plant model in Blender. The goal is to visualize live equipment states such as tank level, pump status, valve position, and other operational conditions from connected systems.

- Sensor / PLC / simulator inputs
- MQTT and edge connectivity
- Telemetry validation and asset mapping
- Blender-based plant visualization
- Live industrial monitoring concept
