# Venkatesh Bokka — IoT Portfolio

Personal engineering portfolio built with Astro.

## Local development

```bash
npm install
npm run dev
```

Open the local URL shown by Astro, usually `http://localhost:4321`.

## Deploy to GitHub Pages

This project is designed for GitHub Pages. After creating the repository, push the files and add a GitHub Actions workflow for Astro deployment.

Repository target:
`venkateshbokka.github.io`
